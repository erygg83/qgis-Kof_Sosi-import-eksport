## Format og avgrensingar

- **SOSI** les `PUNKT` med positivt filserienummer, `OBJTYPE`, valfritt `NAVN` og éin `NØ` eller `NØH`. Filserienummer er identiteten innanfor éi fil. `OBJTYPE` blir bevart som tekst. Fagleg kontroll av verdien krev ein produktprofil. Lesaren støttar SOSI 4.5 med UTF-8 eller ISO8859-1 og avgrensa filhovud. `KOORDSYS` 22, 23 og 25 svarar til EPSG:25832, 25833 og 25835. Eksport bruker ISO8859-1, lokal origo og millimetereining. Vertikalt tek profilen imot `NN2000` og `NN54`, og krev eksplisitt høgdesystem før 3D-eksport. Ukjende hovudfelt, gruppeformat og eigenskapar gir feilmelding. [SOSI 4.5, Kartverket](https://register.geonorge.no/standarder/sosi/del-1-generell-del/sosi-realisering-sosi-gml/4.5), [Kartverket om transformasjonsparametrar](https://objektkatalog.geonorge.no/Objekttype/Index/EAID_7689F6D6_FA50_4fda_910F_F7A8C3C73C65)
- **KOF** les aktive ASCII-oppføringar av netLIN 05 med fast feltbreidd. Filkolonnane X og Y står for nord og aust. Brukaren må oppgi projisert, metrisk CRS ved import og velje eller markere høgdesystem som ukjent. Fila lagrar ingen av dei. Eit blankt høgdefelt er representert som manglande Z i prototypen. Ekstern kompatibilitet for blank høgd står att. Andre aktive blokktypar gir feilmelding. Linjer merkte med minus blir hoppa over etter den dokumenterte statusregelen. [netLIN KOF Filformat](https://www.netlin.no/downloads/netlin/docs/netLIN%20KOF%20Filformat.pdf)
- **QGIS** brukar separate mellombelse lag for punkt med og utan høgd. Eksport skriv heile det aktive laget. Felt for SOSI er `punkt_id`, `objtype` og `navn`. Felt for KOF er `punkt_id`, `temakode`, `merknad` og `berekningskode`. Valfri feltmapping, eksport av fleire lag i same operasjon og koordinattransformasjon høyrer til vidare utvikling.
- Rundturen samanliknar rekkjefølgje, identitet, eigenskapar, koordinatdimensjon og X/Y/Z. Skriving rundar til næraste millimeter. Toleransen er 0,0005 m pluss 2 nm for flyttalsrepresentasjon. Dialogen oppgir om avrunding har skjedd. Interne kontrollar prøver formatet og dei støtta felta.

## Reproduser testen

Køyr frå prosjektmappa i PowerShell. Formatkøyringa gav 7 beståtte testar. Full køyring med QGIS 4.0.2 gav 12 beståtte testar.

```powershell
python -m unittest discover -s tests -p test_formats.py -v
& 'C:/Program Files/QGIS 4.0.2/bin/python-qgis.bat' -m unittest discover -s tests -v
```

Begge filene under `tests/fixtures/` er eigne syntetiske testdata som kan delast og brukast fritt. SOSI-fila følgjer dei dokumenterte koordinatreglane og er laga for å prøve parseren. KOF-fila bruker feltbreiddene i REN-spesifikasjonen. Originaleksempelet frå PDF-en vart kontrollert separat frå teiknplasseringa på side 4. Ingen eksterne testfiler eller utdrag er inkluderte i utvidinga.
